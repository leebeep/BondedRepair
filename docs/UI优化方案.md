# 保税维修系统 UI 优化方案

> 版本：v1.0（2026-11-27）
> 范围：ruoyi-frontend（Vue 3 + Element Plus 2.14 + Vite 6，RuoYi-Vue3 3.9.2）
> 设计方向：专业企业蓝（enterprise navy/blue）、克制阴影、统一圆角、轻量过渡、完整暗黑适配

---

## 一、现状诊断

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 首页无业务价值 | RuoYi 默认宣传页（框架介绍/QQ群/更新日志） | 登录后第一眼无业务信息 ✅ 已改造 |
| 视觉风格陈旧 | 默认 #409EFF 蓝、平直直角卡片、无层级阴影 | "生成感"强，缺乏专业后台质感 |
| 交互反馈不足 | 按钮无按压触感、写操作缺统一 loading/确认 | 操作确定感弱 |
| 列表页风格不统一 | 各模块搜索区/表格/分页排布各异 | 学习成本高 |
| 存量缺陷 | 菜单指向不存在的 workorder/customer 页面；生产构建开启 inline sourcemap | 白屏风险、产物膨胀 |

## 三、设计令牌（Design Tokens）

### 3.1 色彩

| 令牌 | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `--br-bg` | `#F6F8FB` | `#101418` | 页面底色 |
| `--br-card` | `#FFFFFF` | `#1A1F26` | 卡片/面板 |
| `--br-border` | `#E8ECF1` | `#2B2F36` | 边框/分隔线 |
| `--br-text` | `#1E293B` | `#E5E7EB` | 主文字 |
| `--br-muted` | `#64748B` | `#9CA3AF` | 次要文字 |
| `--br-hover` | `#F1F5F9` | `#232A33` | 悬停/表头底色 |
| 主色（建议改） | `#2563EB`（现 `#409EFF`） | 同步调整 | 按钮/链接/激活 |

语义色：成功 `#16A34A` / 警告 `#D97706` / 危险 `#DC2626` / 信息 `#64748B`

### 3.2 圆角与阴影
- 圆角刻度：控件 6px、小控件 4px、卡片/弹窗 12px、图标底 10px
- 阴影：默认无边框阴影，仅 hover `0 6px 16px rgba(15,23,42,.1)`；弹窗用低饱和深阴影

### 3.3 间距与字号
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32
- 字号：页面标题 20–22、面板标题 15/600、正文 14、辅助 12；数字统一 `tabular-nums`

## 四、分阶段实施计划

### 阶段 1：令牌固化 + 主色调整（0.5 天，低风险）
1. `modern-polish.scss` 补齐间距/字号刻度注释规范
2. `src/store/modules/settings.js` 默认 `theme` 改为 `#2563EB`（用户已保存主题不受影响）
3. 业务页面禁止写死 hex，统一 `var(--br-*)` / `var(--el-*)`
4. 关闭生产 sourcemap：`vite.config.js` `sourcemap: false`

### 阶段 2：布局层（1–2 天）
1. 侧边栏：深蓝化（`#1E3A5F → #2563EB` 渐变激活态）或浅色化二选一，菜单分组加间距层次
2. Logo 区与折叠按钮统一高度；TagsView 与内容区间距归一
3. 列表页统一骨架：
   ```
   ┌─ 卡片：搜索区（≤3 条件平铺，更多折叠"展开/收起"）─────────┐
   ├─ 卡片：工具行（左侧标题+统计，右侧 新增/导出/列设置）──────┤
   ├─ 表格（表头灰底 600 字重、行 hover、状态列带色点 Tag）─────┤
   └─ 分页右对齐 + 每页条数选择 ────────────────────────────────┘
   ```
4. 操作按钮规范：主操作 1 个 primary，其余 default，危险操作（删除/作废）靠右红色 plain

### 阶段 3：列表页逐模块统一化（按模块渐进，每模块 0.5–1 天）
- 顺序：物料备案 → 入库 → 工单发料 → 工单收料 → 出库 → 库存台账 → 申报管理
- 统一交互：搜索表单回车即查；金额/数量右对齐；状态列统一 Tag 映射（复用 `utils/bonded.js`）
- 详情从独立页改为 Drawer（保留列表上下文），明细行内嵌展开

### 阶段 4：交互反馈（1 天）
1. 所有写操作：按钮 loading + 成功 `ElMessage` + 刷新列表
2. 审核/申报/作废统一 `ElMessageBox.confirm` 二次确认（危险操作红色按钮）
3. 表单校验：错误就近显示、失焦校验、提交时滚动到首个错误项
4. 首页申报动态复用申报页 60s 轮询思路，加"最近更新时间"提示

### 阶段 5：存量问题清理（0.5 天）
1. 清理 `sys_menu` 中 `bonded/workorder`、`bonded/customer` 两条失效菜单（或补建页面）
2. `package.json`/构建产物检查，移除未用依赖

## 五、验收清单（Pre-Delivery Checklist）

- [ ] 亮色文字对比度 ≥ 4.5:1，暗黑模式同步检查
- [ ] 键盘焦点可见（`:focus-visible` outline）
- [ ] 图标一律使用 Element Plus SVG 图标，不用 emoji
- [ ] 所有可点击元素 hover 200ms 过渡 + cursor: pointer
- [ ] 响应式断点：1280 / 1440 / 1920 三档检查无横向滚动
- [ ] `prefers-reduced-motion` 下无位移动画
- [ ] KPI/表格数字 `tabular-nums` 右对齐
- [ ] 首页接口无权限门槛（登录即可）、各模块接口权限串不变
